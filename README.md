## Sembark E-Commerce — React Assignment
A basic e-commerce web application built with React + TypeScript where users can browse products, filter by category, view product details, and manage a shopping cart.

Tech Stack
- React 18 (CRA + TypeScript template)React-Router, React Query (@tanstack/react-query),State MobX
- StylingInline styles (mobile-responsive)
- E2E TestingCypress

# Getting Started

Installation
- Run these cmd on Terminal:
  - git clone https://github.com/mohit0268/semcart
  - cd semcart
  - npm install
  - npm run dev
Open http://localhost:5173 in your browser.
