Sembark E-Commerce — React Assignment
A basic e-commerce web application built with React + TypeScript where users can browse products, filter by category, view product details, and manage a shopping cart.

Tech Stack
ConcernLibraryFrameworkReact 18 (CRA + TypeScript template)RoutingReact Router v6Data FetchingReact Query (@tanstack/react-query)State ManagementMobX + React Context APIAPIPlatzi Fake Store APIStylingInline styles (mobile-responsive)E2E TestingCypress

Getting Started

Installation
Run these cmd on bash:
git clone https://github.com/mohit0268/semcart
cd sembark-ecommerce
npm install
Running the App
bash: npm run dev
Open http://localhost:30 in your browser.
